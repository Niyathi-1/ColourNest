# 🎨 ColourNest

ColourNest is a lightweight, intuitive mini paint and doodling application built using **Python** and **Tkinter**. It offers a clean, user-friendly canvas designed for quick sketching and digital doodling.

## 🚀 Features

*   **Freehand Drawing:** Smooth, natural brush strokes for seamless sketching.
*   **Different Colors:** A dynamic color palette to bring your doodles to life.
*   **Eraser Tool:** Easily wipe away mistakes or adjust your artwork.
*   **Brush Size Control:** Change the thickness of your brush or eraser on the fly.
*   **Undo & Redo:** Full history control to step backward or forward through your edits.
*   **Clear Canvas:** Wipe the entire board clean with a single click.
*   **Save Artwork:** Export your finished drawings directly as an image file.

## 💻 Installation & Usage

### For Windows Users (Easiest)
1. Head over to the [Releases](https://github.com) section.
2. Download the latest `ColourNest.exe` binary file.
3. Double-click the file to run the application instantly—no installation required!

### For Developers (Running from Source)
If you want to run the raw Python code, make sure you have Python 3 installed, clone the repository, and run:
```bash
python main.py
```
*(Note: Replace `main.py` with your actual main Python filename if it is named differently).*
